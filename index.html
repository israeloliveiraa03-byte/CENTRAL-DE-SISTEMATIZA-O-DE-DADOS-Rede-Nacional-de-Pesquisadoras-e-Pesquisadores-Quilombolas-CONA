📐 Nota Metodológica

Base: 475 formulários coletados via Google Forms (2025–2026). Cada formulário pode registrar até 4 escolas. A análise considera individualmente cada escola registrada, totalizando 655 escolas.


Unificação das escolas: As perguntas equivalentes das Escolas 1, 2, 3 e 4 foram consolidadas em uma única base analítica. Todos os indicadores de escola (racismo, infraestrutura, transporte, alimentação, docentes, gestão) refletem esta base unificada.


Perguntas territoriais (Q1–Q21): Permanecem com base de 475 formulários (fechamento, oferta de EM, evasão, diretrizes, concurso).


Escala de infraestrutura: Adequada → Insuficiente → Precária → Inexistente → Não se aplica. Nos gráficos de "% com inadequação", agrupam-se Precária + Insuficiente + Inexistente.


Escala Likert (transporte/alimentação): Concordo totalmente → Concordo parcialmente → Discordo → Não sei → Não se aplica.


Categorias de resposta: Preservadas exatamente como na base de dados, sem fusão de categorias.


UFs: Todas as 21 unidades federativas com respostas são exibidas em todos os gráficos comparativos por estado.
