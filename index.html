📐 Nota Metodológica

Base primária: 475 formulários Google Forms coletados por pesquisadoras(es) da Rede CONAQ (2025–2026). Cada formulário representa um território/comunidade quilombola.


Escolas: O formulário prevê registro de até 4 escolas por formulário. Todos os dados de escola foram extraídos e consolidados em uma base única de 655 escolas, processando os campos equivalentes das Escolas 1 a 4.


Bases distintas: Dados territoriais (Q1–Q23: fechamento, EM, evasão, diretrizes, concurso, famílias, avaliação) têm base de 475 formulários. Dados de escola (infraestrutura, transporte, alimentação, docentes, racismo, gestão) têm base de 655 escolas.


Categorias: Preservadas exatamente como no formulário original, sem fusão ou simplificação.


Escala de infraestrutura: Adequada / Precária / Inexistente / Insuficiente / Não se aplica / Não sei.


Escala Likert (transporte/alimentação): Concordo totalmente / Concordo parcialmente / Discordo / Não sei informar / Não se aplica.


Filtros: Os filtros de Região, UF e Localização afetam os gráficos de escola (655 registros). Os gráficos territoriais permanecem na base completa de 475 formulários.
